## Python Basics Activities - Unit 1.1— Input, Output, Arithmetic, and Strings

programs 


1. Write a simple Python script to print your name to the console.
2. Write a program that takes user input (name, age, etc.) and prints a
personalized message.
3. Create a Python script that takes two numbers as user input and prints
the result of their multiplication. Include appropriate user prompts and
output statements.
4. Develop a Python script that calculates and prints the result of raising a
user-input base to a user-input exponent without using the ** operator.
5. Write a program that takes coefficients of a quadratic equation as input
and solves for the roots. Handle both real and complex roots.
6. Write a program that takes two input strings and concatenates them.
